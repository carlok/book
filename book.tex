\chapter{Build note}

Compile this draft at least twice so the table of contents and PDF outlines are
stable:

\begin{verbatim}
mkdir -p /tmp/book-build
pdflatex -interaction=nonstopmode -halt-on-error \
  -output-directory=/tmp/book-build book.tex
pdflatex -interaction=nonstopmode -halt-on-error \
  -output-directory=/tmp/book-build book.tex
\end{verbatim}

The standalone study-sheet index entries are preserved in the source article,
but index printing is intentionally disabled in this first integrated draft.
